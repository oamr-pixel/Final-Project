# Ola Amr Portfolio

Personal portfolio site for creative computing, computer vision, and interactive technical projects.

## Live Sections

- Featured case study: temporal video painting with OpenCV and Python
- Project roadmap: six polished portfolio project ideas ready to become GitHub repos
- Skills: computer vision, creative coding, JavaScript, data visualization, and UX polish
- Optional avatar: add `pc.png` in the project root to replace the initials fallback

## Deployment

This is a static website, so it can be hosted on Netlify, GitHub Pages, Cloudflare Pages, or Vercel.

For Netlify Drop, upload the files listed above together in one folder.
